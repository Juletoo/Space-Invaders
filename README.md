The first Space Invaders file is the game following the video assigned, the file called Space Lvl 2 is the modified version where multiple parts of the level as been changed and modified, which also includes a level 2 which is played right after all the aliens in level 1 is destroyed.

How to Start the Project

To start my game, the user first needs to download the files from my GitHub repository.

They then need to open the Level 2 project folder in Visual Studio Code.

The computer must have Python and Pygame installed.

If Pygame is not installed, it can be installed using the command:

python -m pip install pygame-ce

Once everything is installed, the user needs to open the terminal inside the project folder and run:

python main.py

The game's Graphics, Sounds and Font folders must also be in the correct location.

If everything is set up properly, the Space Invaders game window should open.

Game Controls

The player uses the left and right arrow keys or A and D to move the spaceship.

Pressing the spacebar allows the player to shoot lasers.

The goal is to destroy all the aliens and complete both levels.

If the player loses or finishes the game, they can press SPACE to restart.
